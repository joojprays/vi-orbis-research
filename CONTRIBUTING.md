# Contributing / Como ajudar

Start with a small issue identifying one observable behaviour and the evidence needed to establish it. Use English or Portuguese.

For a code change, include the upstream version if relevant, source/licence provenance, reproducible commands, expected output, actual output, and remaining unknowns. Use original synthetic input for loader/shader fixtures. Do not attach title binaries or assets.

Hardware reports should identify console model/southbridge, firmware, toolchain and commit, reproducible steps, memory and timing measurements, and whether the result came from PS4-native code or Linux. Redact usernames, IP addresses, account IDs, secrets and personal filenames before publication.

Do not ask contributors to execute an unreviewed payload or interrupt an ongoing console operation. Propose hardware tests separately; no automatic installation, reboot, filesystem repair, fan tuning or destructive action.

An independently reproduced result is more valuable than a percentage or a promise.
